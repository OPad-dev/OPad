# Terminology Glossary / Glosario de Términos

Standardized bilingual vocabulary for OPad documentation (English and Spanish).
Product, brand, and gaming terms remain in English across both languages.

| English | Español | note |
|---|---|---|
| OPad | OPad | Product name (never translate) |
| osu! | osu! | Game name (never translate) |
| tosu | tosu | Telemetry software name (never translate) |
| Quick Retry | Quick Retry | Touch action during a map (restart beatmap, send `` ` ``) |
| Rapid Trigger | Rapid Trigger | Dynamic switch actuation based on travel direction reversal |
| Hall Effect | Hall Effect | Magnetic sensing technology |
| HID | HID | USB Human Interface Device class |
| OTA | OTA | Over-The-Air firmware update mechanism |
| `opadctl` | `opadctl` | CLI command name (verbatim) |
| map | mapa | osu! beatmap (also acceptable: beatmap) |
| daemon | daemon | Background service process (`opad-daemon`) |
| keypad | teclado / keypad | The physical two-key device |
| switch | interruptor / switch | Key switch mechanism (mechanical MX or magnetic HE) |
| debounce | antirrebote / debounce | Mechanical bounce filtering algorithm |
| reconciliation | reconciliación | Monotonic key counter synchronization algorithm |
| dead zone | zona muerta | Configurable travel threshold without actuation |
| travel | recorrido | Key travel distance in millimeters |
| stroke | pulsación / recorrido | Complete key depression travel |
| firmware | firmware | ESP32-S3 embedded software |
| tray | bandeja del sistema / tray | System tray notification area and icon |
| Named Pipes | Named Pipes | Windows IPC transport |
| Unix domain socket | socket de dominio Unix | Linux IPC transport |
| bootloader | bootloader / cargador de arranque | ESP32-S3 ROM download bootloader mode |
| feed | feed | HTTP software release distribution channel |
| bottom-out | fondo de recorrido / bottom-out | Fully depressed switch position |
| rest position | posición de reposo | Switch position when released / untouched |
| carrier | carrier / placa base | The main internal board connecting the Waveshare display board |
| module | módulo | Swappable switch daughterboard (MX or HE) |
